# Forest Watch art

These two PNGs are the exact generated images recovered from the unfinished Crystal Guard prototype. Their hashes and grid boundaries are recorded in `manifest.json`. No new art was generated for this recovery. The visuals are original fantasy illustrations inspired by nostalgic isometric RPGs; they are not extracted game assets.

The atlas contains four heroes with an idle and an attack/cast pose each, four monster designs and four structures. The environment sheet contains six props. Runtime animation uses those poses, movement bobbing and effects; it is not a complete eight-direction skeletal animation set. The renderer measures alpha bounds within the recorded cells and anchors sprites to the ground.
